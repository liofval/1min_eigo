日本語訳

もしもの前に作る計画

緊急時の計画は、落ち着いたひとつの会話から始められます。

電話が使えないとき、どこで会うかを家族に聞くことができます。

家の近くの場所と、少し離れた場所を選ぶこともできます。

大切な電話番号を紙に書いておくこともできます。

計画を作ることは、毎日悪いことを予想するという意味ではありません。

問題が起きる前に、お互いを大切にするという意味です。

計画は短く、わかりやすく、覚えやすいものでかまいません。

あとで見直し、必要なら変えることもできます。

次に何をすればよいかわかっていると、人は孤独を感じにくくなります。

備えることは真面目に聞こえますが、愛情から始まります。

もう一度読んで、この題材を自分のやさしい英語で説明する練習をしましょう。
